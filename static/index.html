AskWhiz Extractor

Drop in a handbook PDF, it gets read and organized automatically, and anything the computer couldn't read gets flagged for you to check.

Advanced

Add a handbook

Any handbook PDF works, not just the ones already here. Give it a name and drop the file in -- it gets processed automatically, and you'll be taken straight to whatever's worth a quick look.

Fine-tuning for one handbook: which pages to skip, running headers to strip, known typos to fix, and how headings are detected. New handbooks work fine with none of this set -- these are refinements, not requirements.

Manual corrections

For content a PDF parser can't read on its own -- a table that's really a pasted screenshot, a diagram, anything flagged for review on the Handbooks tab -- type in the correct text here by hand. It gets stitched into the results at the right spot. Nothing here counts until verified is checked, confirming a human checked it against the actual printed page.

Build a search index

Turns the processed handbooks into the search index the chatbot reads from, then asks it the gold questions to check it still finds the right answers (Gate 4). Each build goes into a new numbered folder, so earlier versions stay untouched. Building does not change the chatbot. The chatbot only uses an index after someone copies a passing version into the chatbot project.

Index versions

Newest first. Scores are from the gold questions: how often the right handbook section came back first, in the top 3, and in the top 5. Average rank score (MRR) is 1.0 when every answer is first.

Any page can be corrected here, not just ones the review queue flagged -- its heuristics catch tables and diagrams, but not everything (a two-column layout read in the wrong order, for instance, won't trip any of them). If the extracted text doesn't match the page, fix it below.
